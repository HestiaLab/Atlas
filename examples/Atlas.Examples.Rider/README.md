# Atlas Rider-style example

This non-packable Blazor WebAssembly application demonstrates a Rider-inspired IDE layout built
only from the public `Atlas.Blazor` component surface. It includes Project, Editor, Services and
Terminal groups, nested splitters, toolbars, a top command bar and a status bar.

Run from the repository root:

```powershell
dotnet run --project examples/Atlas.Examples.Rider/Atlas.Examples.Rider.csproj
```

The styling intentionally evokes an IDE workspace without copying Rider product assets or branding.
